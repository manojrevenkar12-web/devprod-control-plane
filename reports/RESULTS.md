# Results

Generated by `devprod run` from `reports/results.json`. Ten simulated weeks of a 42-engineer monorepo (25 modules, Python and TypeScript) and 260 customer AWS accounts. *Baseline* is a good ordinary setup: path-filtered workflows, one job per module, a fixed runner fleet, people triaging CI failures, staging then everyone. *Control plane* is this repository. Both worlds share their randomness by key, so the same test flakes on the same commit and the same change breaks the same thing.
